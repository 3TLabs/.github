# Support at 3T Labs

Welcome! We are excited you are using tools and projects built by **3T Labs**.

Here is how you can get help, ask questions, or report problems across our repositories:

---

## 1. Documentation & Guides
Check the project-specific `README.md` and `docs/` directory in each repository for setup instructions, API references, configuration guides, and usage examples.

---

## 2. GitHub Discussions
For general questions, architecture discussions, or sharing ideas:
- Visit [3T Labs Discussions](https://github.com/orgs/3TLabs/discussions).
- Check repository-level Discussions if enabled for a specific project.

---

## 3. Reporting Bugs & Requesting Features
If you encountered a bug or have an idea for improvement:
- Search existing issues to see if it has already been reported.
- Open a new issue in the specific repository using our standard issue templates (Bug Report or Feature Request).

---

## 4. Security Vulnerabilities
Do not use public issue trackers for sensitive security issues. Please review our [Security Policy](SECURITY.md) for instructions on confidential reporting.

---
