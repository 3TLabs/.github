### 🚀 What We Do

At **3T Labs**, we build reliable tooling, automation workflows, and cloud-native experiments designed to streamline development and operations.

- ⚙️ **Automation** — CI/CD pipelines, task runners, workflow orchestrators, and bots.
- ☸️ **Kubernetes & DevOps** — Infrastructure as code, cluster tooling, Helm charts, and platform utilities.
- 🐹 **Go & Developer Tooling** — Fast, single-binary CLI utilities and developer productivity tools.
- 🐳 **Containers & Cloud Native** — Minimal container images, Docker tooling, and cloud integrations.
- 🔧 **Scripts & Utilities** — Practical day-to-day sysadmin, developer, and automation scripts.
