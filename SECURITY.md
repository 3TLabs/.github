# Security Policy

The **3T Labs** team takes security seriously. We appreciate the responsible disclosure of any vulnerabilities found across our repositories.

---

## Supported Versions

Please see individual repositories for project-specific version support tables. In general, security fixes are prioritized for the latest minor release of active projects.

---

## Reporting a Vulnerability

If you discover a security vulnerability in any 3T Labs repository:

1. **GitHub Private Vulnerability Reporting (Preferred)**:
   - Go to the affected repository on GitHub.
   - Click the **Security** tab.
   - Click **Report a vulnerability** to open an advisory draft.

2. **Email (Alternative)**:
   - Send an email to: <!-- TODO: Set security email --> **security@3tlabs.dev** (or contact [@stavrosl7](https://github.com/stavrosl7), [@gtourgianas](https://github.com/gtourgianas), or [@zacharatos](https://github.com/zacharatos)).
   - Include a detailed description, reproduction steps or proof-of-concept, affected versions, and potential impact.

---

## Response Timeline

- **Initial Response**: We aim to acknowledge receipt of security reports within 48-72 hours.
- **Triage & Assessment**: We will assess the severity and determine a remediation plan.
- **Resolution & Release**: Once a fix is verified, a patched release and corresponding advisory will be published.

Please do not disclose security issues publicly before they have been addressed.
